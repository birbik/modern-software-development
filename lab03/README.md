# Лабораторная работа 3. Условия и логические выражения

**Вариант:** 2 — Заполненность хранилища

## Как запустить

Все файлы находятся в папке `lab03`. Запуск из терминала, находясь в этой папке:

```bash
python minimum.py
python calculator.py
python point.py
python variant.py
python leap_year.py
```

Если команда `python` не найдена, используйте `python3`.

---

## Описание программ

| Файл | Назначение |
|---|---|
| `minimum.py` | Поиск минимума трёх целых чисел без встроенных функций `min`/`max` |
| `calculator.py` | Калькулятор четырёх операций с проверкой деления на ноль |
| `point.py` | Проверка принадлежности точки прямоугольнику `[0, 5] × [0, 3]` |
| `variant.py` | Индивидуальный вариант: категория заполненности хранилища |
| `leap_year.py` | Определение високосного года |

| Поле | Ввод |
|---|---|
| Первое число | 2 |
| Второе число | 10 |
| Третье число | 3 |

```

```

- Инициализация: `minimum = 2`

- Проверка `c < minimum` (`3 < 2`): Ложь $\rightarrow$ `minimum = 2`

Фактический результат: совпадает с ожидаемым.

### variant.py — Заполненность хранилища

Категории:
- `0–49`: Свободно

- `90–100`: Почти заполнено

| `89` | Непосредственно до порога 90 | `Мало места` | `Мало места` (совпадает) |

### leap_year.py

Правило: делится на 400 ЛИБО (делится на 4 И не делится на 100). Диапазон года: `1–9999`.

#### Таблица «ввод → ожидаемый ответ → фактический ответ»

| Ввод | Описание проверки | Ожидаемый ответ | Фактический ответ |
|---|---|---|---|
| `1900` | Делится на 100, но не на 400 | `Нет` | `Нет` (совпадает) |
| `2000` | Делится на 400 | `Да` | `Да` (совпадает) |
| `2024` | Делится на 4 и не делится на 100 | `Да` | `Да` (совпадает) |
| `2023` | Не делится на 4 | `Нет` | `Нет` (совпадает) |
| `0` | Выход за диапазон снизу | `Ошибка диапазона` | `Ошибка диапазона` (совпадает) |

#### Проверка 1 — 1900 год  

| Поле | Ввод |
|---|---|
| Год | 1900 |

Ожидаемый результат:
```
Нет
```

- 1900 % 400 != 0
- 1900 % 4 == 0, но 1900 % 100 == 0 (условие не выполнено)
- Год не високосный.

Фактический результат: совпадает с ожидаемым.
