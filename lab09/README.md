## Ответы на вопросы и обоснование решений

### Какую ошибку выявляет таблица 2×3
Прямоугольная таблица, в которой число строк не равно числу столбцов (например, 2 строки и 3 столбца), позволяет сразу выявить две типичные ошибки:
1. **Перепутанные индексы:** обращение `matrix[column][row]` вместо `matrix[row][column]`. Для квадратной таблицы $N \times N$ эта ошибка может маскироваться, а для матрицы $2 \times 3$ вызовет `IndexError` при попытке обратиться к строке с индексом 2.
2. **Предположение о квадратности матрицы:** использование `len(matrix)` вместо `len(matrix[0])` при обходе столбцов. В матрице $2 \times 3$ цикл по `range(len(matrix))` обработает только 2 столбца вместо 3, потеряв последний столбец.

### Почему нельзя создавать таблицу как `[[0] * columns] * rows`
Оператор умножения списка `[row] * rows` не создаёт новые независимые строки, а дублирует ссылку на один и тот же список в памяти. 
В результате все элементы внешнего списка ссылаются на единственный внутренний список. Изменение ячейки в одной строке `matrix[0][0] = 7` немедленно приведёт к изменению этой же позиции во всех остальных строках (`matrix[1][0] == 7`). 

Правильный способ создания матрицы с независимыми строками — списковое включение:
```python
matrix = [[0] * columns for _ in range(rows)]
```
Здесь на каждой итерации выражение `[0] * columns` создаёт новый отдельный список.

### Чем копия внешнего списка отличается от копирования строк
Метод `matrix.copy()` выполняет *поверхностное копирование* (shallow copy): создаётся новый внешний список, но его элементами остаются ссылки на те же исходные списки-строки. При изменении ячейки `copy_matrix[0][0] = 99` изменится и значение в исходной матрице `matrix[0][0]`.

Чтобы получить полностью независимую копию матрицы, необходимо создать копию каждой строки:
```python
deep_copy = [row.copy() for row in matrix]
```

### Трассировка рекурсивного вычисления `factorial(3)`
Рекурсивная функция состоит из прямого хода (углубление рекурсии с сохранением контекста в стеке вызовов) и обратного хода (возврат значений из базового случая):
1. **Прямой ход (цепочка вызовов):**
   - Вызов `factorial(3)`: условие $3 == 0$ ложно, ожидает результат $3 \times \text{factorial}(2)$.
   - Вызов `factorial(2)`: условие $2 == 0$ ложно, ожидает результат $2 \times \text{factorial}(1)$.
   - Вызов `factorial(1)`: условие $1 == 0$ ложно, ожидает результат $1 \times \text{factorial}(0)$.
   - Вызов `factorial(0)`: базовый случай ($0 == 0$), возвращает `1`.
2. **Обратный ход (цепочка возвратов):**
   - `factorial(1)` вычисляет $1 \times 1$ и возвращает `1`.
   - `factorial(2)` вычисляет $2 \times 1$ и возвращает `2`.
   - `factorial(3)` вычисляет $3 \times 2$ и возвращает `6`.

## Проверки

### 1. row_sums(matrix) и column_sums(matrix)

Правила:
- `row_sums(matrix)` возвращает суммы элементов каждой строки. Для `[]` возвращает `[]`.
- `column_sums(matrix)` возвращает суммы элементов каждого столбца. Для `[]` возвращает `[]`.
- Исходная матрица не изменяется.

#### Таблица «ввод → ожидаемый ответ → фактический ответ»

| Матрица | Описание проверки | Ожидаемые суммы строк | Ожидаемые суммы столбцов | Фактический результат |
|---|---|---|---|---|
| `[[1, 2, 3], [4, 5, 6]]` | Прямоугольная матрица 2x3 | `[6, 15]` | `[5, 7, 9]` | Совпадает |
| `[[7]]` | Матрица 1x1 | `[7]` | `[7]` | Совпадает |
| `[[1], [-1], [0]]` | Матрица-столбец 3x1 | `[1, -1, 0]` | `[0]` | Совпадает |
| `[]` | Пустая матрица | `[]` | `[]` | Совпадает |
| `[[-2, 0, 3], [4, -5, 6]]` | Контрольная матрица вариантов | `[1, 5]` | `[2, -5, 9]` | Совпадает |

#### Проверка 1 — контрольная матрица `[[-2, 0, 3], [4, -5, 6]]`
- Сумма строки 0: $(-2) + 0 + 3 = 1$
- Сумма строки 1: $4 + (-5) + 6 = 5$
- Итого суммы строк: `[1, 5]`
- Сумма столбца 0: $(-2) + 4 = 2$
- Сумма столбца 1: $0 + (-5) = -5$
- Сумма столбца 2: $3 + 6 = 9$
- Итого суммы столбцов: `[2, -5, 9]`

### 2. diagonal_pattern(size)

Правила:
- Квадратная таблица размера `size x size`.
- Элементы главной диагонали (`r == c`): `0`.
- Элементы выше главной диагонали (`r < c`): `1`.
- Элементы ниже главной диагонали (`r > c`): `2`.
- Строки матрицы должны быть независимыми объектами.

#### Таблица «размер → ожидаемый узор → фактический результат»

| Размер `size` | Ожидаемый узор | Фактический результат |
|---|---|---|
| `1` | `[[0]]` | `[[0]]` (совпадает) |
| `2` | `[[0, 1], [2, 0]]` | `[[0, 1], [2, 0]]` (совпадает) |
| `3` | `[[0, 1, 1], [2, 0, 1], [2, 2, 0]]` | `[[0, 1, 1], [2, 0, 1], [2, 2, 0]]` (совпадает) |

#### Проверка 1 — размер 3x3
- Строка 0: `(0,0) -> 0`, `(0,1) -> 1`, `(0,2) -> 1` $\rightarrow$ `[0, 1, 1]`
- Строка 1: `(1,0) -> 2`, `(1,1) -> 0`, `(1,2) -> 1` $\rightarrow$ `[2, 0, 1]`
- Строка 2: `(2,0) -> 2`, `(2,1) -> 2`, `(2,2) -> 0` $\rightarrow$ `[2, 2, 0]`

### 3. transform(matrix) — Вариант 2: положительные заменить на 1

Правила:
- Создаётся новая матрица той же размерности.
- Положительные числа ($x > 0$) заменяются на `1`.
- Отрицательные числа и нули ($x \le 0$) сохраняются без изменений.
- Для `[]` возвращается `[]`.
- Исходная матрица остаётся неизменной.

#### Таблица «ввод → ожидаемый ответ → фактический ответ»

| Матрица | Описание проверки | Ожидаемый ответ | Фактический ответ |
|---|---|---|---|
| `[[-2, 0, 3], [4, -5, 6]]` | Контрольная матрица из методички | `[[-2, 0, 1], [1, -5, 1]]` | `[[-2, 0, 1], [1, -5, 1]]` (совпадает) |
| `[]` | Пустая матрица | `[]` | `[]` (совпадает) |
| `[[0, -1], [-3, 0]]` | Матрица без положительных чисел | `[[0, -1], [-3, 0]]` | `[[0, -1], [-3, 0]]` (совпадает) |
| `[[2, 5], [10, 1]]` | Только положительные числа | `[[1, 1], [1, 1]]` | `[[1, 1], [1, 1]]` (совпадает) |

#### Проверка 1 — контрольная матрица `[[-2, 0, 3], [4, -5, 6]]`
- Строка 0:
  - `-2`: не больше нуля $\rightarrow$ сохраняется `-2`
  - `0`: не больше нуля $\rightarrow$ сохраняется `0`
  - `3`: больше нуля $\rightarrow$ заменяется на `1`
  - Итог строки 0: `[-2, 0, 1]`
- Строка 1:
  - `4`: больше нуля $\rightarrow$ заменяется на `1`
  - `-5`: не больше нуля $\rightarrow$ сохраняется `-5`
  - `6`: больше нуля $\rightarrow$ заменяется на `1`
  - Итог строки 1: `[1, -5, 1]`
