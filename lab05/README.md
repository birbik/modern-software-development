# Лабораторная работа 5. Обработка строк

**Вариант:** 2 — Слова, заканчивающиеся на букву «я»

## Как запустить

Все файлы находятся в папке `lab05`. Запуск из терминала, находясь в этой папке:

```bash
python normalize.py
python palindrome.py
python replace.py
python variant.py
python palindrome_loop.py
```

Если команда `python` не найдена, используйте `python3`.

---

## Описание программ

| Файл | Назначение |
|---|---|
| `normalize.py` | Нормализация текста: удаление лишних пробелов с сохранением регистра, подсчёт длин и количества слов |
| `palindrome.py` | Проверка строки на палиндром с игнорированием регистра и пробелов с помощью среза `[::-1]` |
| `replace.py` | Подсчёт количества двоеточий и замена их на дефисы |
| `variant.py` | Индивидуальный вариант: поиск слов, заканчивающихся на букву «я», с очисткой от краевой пунктуации |
| `palindrome_loop.py` | Проверка строки на палиндром с помощью цикла по первой половине очищенной строки |

### palindrome.py

Правила: игнорировать регистр (`.lower()`) и пробелы `" "`. Остальные символы (включая знаки препинания) сравниваются как есть. Пустая очищенная строка $\rightarrow$ `Нет текста`.

#### Таблица «ввод → ожидаемый ответ → фактический ответ»

| Ввод | Описание проверки | Ожидаемый ответ | Фактический ответ |
|---|---|---|---|
| `А роза упала на лапу Азора` | Классический палиндром с пробелами и разным регистром | `Палиндром` | `Палиндром` (совпадает) |
| `а    ` | Один символ с пробелами | `Палиндром` | `Палиндром` (совпадает) |
| `    ` | Строка только из пробелов | `Нет текста` | `Нет текста` (совпадает) |
| `Python` | Обычное слово, не палиндром | `Не палиндром` | `Не палиндром` (совпадает) |
| `А!` | Различие из-за знака препинания | `Не палиндром` | `Не палиндром` (совпадает) |
| `Шалаш` | Палиндром в разном регистре | `Палиндром` | `Палиндром` (совпадает) |

#### Проверка 1 — классическая фраза

| Поле | Ввод |
|---|---|
| Текст | `А роза упала на лапу Азора` |

Ожидаемый результат:
```
Палиндром
```

Трассировка:
- `lower()`: `а роза упала на лапу азора`
- `replace(" ", "")`: `арозаупаланалапуазора`
- Обратный срез совпадает с прямой строкой $\rightarrow$ `Палиндром`.

Фактический результат: совпадает с ожидаемым.

#### Проверка 2 — один символ и пробелы

| Поле | Ввод |
|---|---|
| Текст | `а    ` |

Ожидаемый результат:
```
Палиндром
```

Трассировка:
- Очищенная строка: `а` (длина 1).
- Строка из одного символа всегда равна своему обратному срезу $\rightarrow$ `Палиндром`.

Фактический результат: совпадает с ожидаемым.

#### Проверка 3 — строка из пробелов

| Поле | Ввод |
|---|---|
| Текст | `    ` |

Ожидаемый результат:
```
Нет текста
```

Трассировка:
- После удаления пробелов длина строки равна 0 $\rightarrow$ `Нет текста`.

Фактический результат: совпадает с ожидаемым.

#### Проверка 4 — слово не палиндром

| Поле | Ввод |
|---|---|
| Текст | `Python` |

Ожидаемый результат:
```
Не палиндром
```

Трассировка:
- Очищенная строка: `python`.
- Обратный срез: `nohtyp` $\ne$ `python` $\rightarrow$ `Не палиндром`.

Фактический результат: совпадает с ожидаемым.

#### Проверка 5 — знак препинания

| Поле | Ввод |
|---|---|
| Текст | `А!` |

Ожидаемый результат:
```
Не палиндром
```

Трассировка:
- Очищенная строка: `а!`.
- Обратный срез: `!а` $\ne$ `а!` (знаки препинания по условию не удаляются) $\rightarrow$ `Не палиндром`.

Фактический результат: совпадает с ожидаемым.

### variant.py — Слова на букву «я»

Условие отбора: слово заканчивается на букву «я» (`cleaned.endswith("я")`) после удаления краевых знаков `.,!?;:` и перевода в нижний регистр.

#### Таблица «ввод → ожидаемый ответ → фактический ответ»

| Ввод | Описание проверки | Ожидаемый ответ | Фактический ответ |
|---|---|---|---|
| `Анна, армия! Я читаю. Книга, край, рама.` | Контрольный текст для вариантов | `армия`<br>`я`<br>Количество: `2` | `армия`<br>`я`<br>Количество: `2` (совпадает) |
| `Анна, армия! Я читаю.` | Короткий проверочный текст | `армия`<br>`я`<br>Количество: `2` | `армия`<br>`я`<br>Количество: `2` (совпадает) |
| `!!!` | Строка только из знаков пунктуации | `Нет совпадений`<br>Количество: `0` | `Нет совпадений`<br>Количество: `0` (совпадает) |
| `""` | Пустой ввод | `Нет совпадений`<br>Количество: `0` | `Нет совпадений`<br>Количество: `0` (совпадает) |
| `Кот и собака.` | Текст без подходящих слов | `Нет совпадений`<br>Количество: `0` | `Нет совпадений`<br>Количество: `0` (совпадает) |
| `Земля, вода, заря, трава.` | Несколько подходящих слов | `земля`<br>`заря`<br>Количество: `2` | `земля`<br>`заря`<br>Количество: `2` (совпадает) |

#### Проверка 1 — контрольный текст

| Поле | Ввод |
|---|---|
| Текст | `Анна, армия! Я читаю. Книга, край, рама.` |

Ожидаемый результат:
```
армия
я
Количество: 2
```

Ручной расчёт / трассировка слов:
1. `Анна,` $\rightarrow$ `анна` $\rightarrow$ не заканчивается на «я».
2. `армия!` $\rightarrow$ `армия` $\rightarrow$ заканчивается на «я» $\rightarrow$ подходит.
3. `Я` $\rightarrow$ `я` $\rightarrow$ заканчивается на «я» $\rightarrow$ подходит.
4. `читаю.` $\rightarrow$ `читаю` $\rightarrow$ не подходит.
5. `Книга,` $\rightarrow$ `книга` $\rightarrow$ не подходит.
6. `край,` $\rightarrow$ `край` $\rightarrow$ не подходит.
7. `рама.` $\rightarrow$ `рама` $\rightarrow$ не подходит.
- Итог: 2 подходящих слова (`армия`, `я`).

Фактический результат: совпадает с ожидаемым.

### palindrome_loop.py

Алгоритм обходит первую половину очищенной строки (`range(len(cleaned) // 2)`) и сравнивает симметричные символы `cleaned[i]` и `cleaned[len - 1 - i]`.

#### Таблица «ввод → ожидаемый ответ → фактический ответ»

| Ввод | Описание проверки | Ожидаемый ответ | Фактический ответ |
|---|---|---|---|
| `А роза упала на лапу Азора` | Классический палиндром | `Палиндром` | `Палиндром` (совпадает) |
| `а    ` | Один символ | `Палиндром` | `Палиндром` (совпадает) |
| `    ` | Только пробелы | `Нет текста` | `Нет текста` (совпадает) |
| `Python` | Не палиндром | `Не палиндром` | `Не палиндром` (совпадает) |
| `А!` | Не палиндром (пунктуация) | `Не палиндром` | `Не палиндром` (совпадает) |
| `Шалаш` | Палиндром | `Палиндром` | `Палиндром` (совпадает) |

#### Проверка 1 — сравнение с решением через срез

На всех тестовых наборах (`А роза упала на лапу Азора`, `а    `, `    `, `Python`, `А!`, `Шалаш`) результаты работы `palindrome_loop.py` полностью совпадают с результатами `palindrome.py`.
