# Лабораторная работа 1. Первые программы на Python

**Вариант:** 2 — Книжный магазин (Учебники / Сборники задач)

## Как запустить

Все файлы находятся в папке `lab01`. Запуск из терминала, находясь в этой папке:

```bash
python hello.py
python profile.py
python workload.py
python debug.py
python swap.py
python variant.py
```

Если команда `python` не найдена, используйте `python3`.

### debug.py

#### Фрагмент А

- **Ошибка:** переменные содержат строки `"2"` и `"3"`. Оператор `+` для строк выполняет конкатенацию → результат `"23"`.
- **Исправление:** преобразовать строки в числа через `int()`.
- **Ожидаемый результат:** `5`

#### Фрагмент Б

- **Ошибка:** `input()` возвращает строку. `"17" + 1` вызывает `TypeError`.
- **Исправление:** обернуть `input()` в `int()`.
- **Ввод:** `17`
- **Ожидаемый результат:** `18`

#### Фрагмент В

- **Ошибка:** в выражении `first + second + third / 3` деление выполняется раньше сложения (приоритет операций). Делится только `third`, результат: `4 + 7 + 3.333... ≈ 14.33`.
- **Исправление:** скобки `(first + second + third) / 3`.
- **Ожидаемый результат:** `7.0`

#### Дополнительная проверка — другие значения

Для чисел `10`, `20`, `30`:
- Среднее: (10 + 20 + 30) / 3 = 20.0
