# Лабораторная работа 4. Циклы, счётчики и накопители

**Вариант:** 2 — Отрицательные числа

## Как запустить

Все файлы находятся в папке `lab04`. Запуск из терминала, находясь в этой папке:

```bash
python range_numbers.py
python statistics.py
python positive_input.py
python variant.py
python prime.py
```

Если команда `python` не найдена, используйте `python3`.

---

## Описание программ

| Файл | Назначение |
|---|---|
| `range_numbers.py` | Вывод всех целых чисел от `a` до `b` включительно в прямом и обратном направлении |
| `statistics.py` | Вычисление суммы, количества положительных чисел и максимума последовательности без списка |
| `positive_input.py` | Запрос целых чисел в цикле до первого положительного с подсчётом отклонённых попыток |
| `variant.py` | Индивидуальный вариант: подсчёт количества и суммы отрицательных чисел за один цикл |
| `prime.py` | Проверка простоты числа перебором делителей до квадратного корня |

### prime.py

Правило: целое $n \ge 2$ является простым, если у него нет делителей от $2$ до $\lfloor\sqrt{n}\rfloor$ (условие `divisor * divisor <= n`).

#### Таблица «ввод → ожидаемый ответ → фактический ответ»

| Ввод | Описание проверки | Ожидаемый ответ | Фактический ответ |
|---|---|---|---|
| `2` | Наименьшее простое число | `Простое` | `Простое` (совпадает) |
| `9` | Составное число ($3 \times 3$) | `Составное` | `Составное` (совпадает) |
| `17` | Простое число | `Простое` | `Простое` (совпадает) |
| `49` | Составное число ($7 \times 7$) | `Составное` | `Составное` (совпадает) |

#### Проверка 1 — число 2

| Поле | Ввод |
|---|---|
| Число n | 2 |

Ожидаемый результат:
```
Простое
```

Трассировка:
- `divisor = 2`: `2 * 2 <= 2` $\rightarrow$ `4 <= 2` (Ложь).
- Цикл завершается без проверки деления, `is_prime = True`.

Фактический результат: совпадает с ожидаемым.

#### Проверка 2 — число 9

| Поле | Ввод |
|---|---|
| Число n | 9 |

Ожидаемый результат:
```
Составное
```

Трассировка:
- `divisor = 2`: `4 <= 9` (Истина), `9 % 2 != 0`, `divisor = 3`.
- `divisor = 3`: `9 <= 9` (Истина), `9 % 3 == 0` $\rightarrow$ `is_prime = False`, `break`.

Фактический результат: совпадает с ожидаемым.

#### Проверка 3 — число 17

| Поле | Ввод |
|---|---|
| Число n | 17 |

Ожидаемый результат:
```
Простое
```

Трассировка:
- Проверяются делители 2, 3, 4: ни один не делит 17 нацело.
- При `divisor = 5`: `25 <= 17` (Ложь) $\rightarrow$ цикл завершён, делителей нет.

Фактический результат: совпадает с ожидаемым.

#### Проверка 4 — число 49

| Поле | Ввод |
|---|---|
| Число n | 49 |

Ожидаемый результат:
```
Составное
```

Трассировка:
- Проверяются 2, 3, 4, 5, 6 — остаток ненулевой.
- При `divisor = 7`: `49 % 7 == 0` $\rightarrow$ `is_prime = False`, `break`.

Фактический результат: совпадает с ожидаемым.
