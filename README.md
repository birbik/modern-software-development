# Современные технологии разработки ПО

Учебный репозиторий с лабораторными работами по курсу **«Современные технологии разработки программного обеспечения»**.

- **Индивидуальный вариант:** **2** (выполнен во всех лабораторных работах)
- **Язык программирования:** Python 3.10+

---
