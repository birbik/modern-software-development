# Лабораторная работа 6. Списки и обработка наборов данных

**Вариант:** 2 — Отрицательные числа

## Как запустить

Все файлы находятся в папке `lab06`. Запуск из терминала, находясь в этой папке:

```bash
python statistics.py
python transform.py
python positions.py
python variant.py
python unique.py
```

Если команда `python` не найдена, используйте `python3`.

---

## Описание программ

| Файл | Назначение |
|---|---|
| `statistics.py` | Расчёт базовых статистических показателей числового списка: количество, сумма, минимум, максимум, среднее арифметическое |
| `transform.py` | Замена отрицательных чисел на их модули с сохранением исходного списка |
| `positions.py` | Определение всех индексов максимального элемента списка с помощью `enumerate()` |
| `variant.py` | Индивидуальный вариант 2: фильтрация отрицательных чисел, вычисление количества, суммы и создание отсортированной копии |
| `unique.py` | Удаление повторяющихся элементов списка с сохранением порядка первого появления без использования `set` |

### transform.py

Правила обработки:
- Формируется новый список, в котором все отрицательные числа заменены на их модули (`abs()`).
- Исходный список сохраняется неизменным.
- Пустой ввод формирует два пустых списка.

#### Таблица «ввод → ожидаемый ответ → фактический ответ»

| Ввод | Описание проверки | Ожидаемый ответ | Фактический ответ |
|---|---|---|---|
| `-2 0 5 -2` | Контрольный пример из методички | Исходный: `[-2, 0, 5, -2]`<br>Новый: `[2, 0, 5, 2]` | Исходный: `[-2, 0, 5, -2]`<br>Новый: `[2, 0, 5, 2]` (совпадает) |
| `""` | Пустой ввод | Исходный: `[]`<br>Новый: `[]` | Исходный: `[]`<br>Новый: `[]` (совпадает) |
| `1 2 3` | Только положительные числа | Исходный: `[1, 2, 3]`<br>Новый: `[1, 2, 3]` | Исходный: `[1, 2, 3]`<br>Новый: `[1, 2, 3]` (совпадает) |
| `-7` | Одно отрицательное число | Исходный: `[-7]`<br>Новый: `[7]` | Исходный: `[-7]`<br>Новый: `[7]` (совпадает) |

#### Проверка 1 — контрольный пример со смешанными числами

| Поле | Ввод |
|---|---|
| Числа | `-2 0 5 -2` |

Ожидаемый результат:
```
Исходный список: [-2, 0, 5, -2]
Новый список: [2, 0, 5, 2]
```

Трассировка поэлементного преобразования:
- Исходный список `numbers`: `[-2, 0, 5, -2]`
- Элемент 1: `-2` $\rightarrow$ `abs(-2) = 2`
- Элемент 2: `0` $\rightarrow$ `abs(0) = 0`
- Элемент 3: `5` $\rightarrow$ `abs(5) = 5`
- Элемент 4: `-2` $\rightarrow$ `abs(-2) = 2`
- Новый список `transformed`: `[2, 0, 5, 2]`
- Исходный список `numbers` остался неизменным: `[-2, 0, 5, -2]`.

Фактический результат: совпадает с ожидаемым.

#### Проверка 2 — пустой ввод

|---|---|

Ожидаемый результат:

#### Проверка 3 — неотрицательные числа

### positions.py

Правила обработки:
- Находится максимальный элемент списка.
- С помощью `enumerate()` определяются все индексы, на которых расположен максимум (индексация с 0).
- При пустом списке выводится `Нет данных`.

#### Таблица «ввод → ожидаемый ответ → фактический ответ»

| Ввод | Описание проверки | Ожидаемый ответ | Фактический ответ |
|---|---|---|---|
| `3 7 2 7` | Максимум встречается несколько раз | `[1, 3]` | `[1, 3]` (совпадает) |
| `7 7` | Все элементы равны максимуму | `[0, 1]` | `[0, 1]` (совпадает) |
| `-3 -1 -2` | Отрицательные числа, один максимум | `[1]` | `[1]` (совпадает) |
| `5` | Единственный элемент | `[0]` | `[0]` (совпадает) |
| `""` | Пустой ввод | `Нет данных` | `Нет данных` (совпадает) |

#### Проверка 1 — несколько максимумов

| Поле | Ввод |
|---|---|
| Числа | `3 7 2 7` |

Ожидаемый результат:
```
[1, 3]
```

Трассировка с `enumerate()`:
- `numbers = [3, 7, 2, 7]`
- `max_val = max(numbers) = 7`
- `i = 0, val = 3`: $3 \ne 7$
- `i = 1, val = 7`: $7 == 7 \rightarrow$ добавляем индекс 1
- `i = 2, val = 2`: $2 \ne 7$
- `i = 3, val = 7`: $7 == 7 \rightarrow$ добавляем индекс 3
- Итоговый список индексов: `[1, 3]`

Фактический результат: совпадает с ожидаемым.

#### Проверка 2 — два равных максимальных числа

| Поле | Ввод |
|---|---|
| Числа | `7 7` |

Ожидаемый результат:
```
[0, 1]
```

Трассировка:
- `numbers = [7, 7]`, `max_val = 7`.
- `(0, 7)` $\rightarrow$ индекс 0.
- `(1, 7)` $\rightarrow$ индекс 1.
- Результат: `[0, 1]`.

Фактический результат: совпадает с ожидаемым.

#### Проверка 3 — отрицательные числа

| Поле | Ввод |
|---|---|
| Числа | `-3 -1 -2` |

Ожидаемый результат:
```
[1]
```

Трассировка:
- `numbers = [-3, -1, -2]`
- `max_val = max([-3, -1, -2]) = -1`
- `(0, -3)` $\rightarrow -3 \ne -1$
- `(1, -1)` $\rightarrow -1 == -1 \rightarrow$ индекс 1
- `(2, -2)` $\rightarrow -2 \ne -1$
- Результат: `[1]`.

Фактический результат: совпадает с ожидаемым.

#### Проверка 4 — пустой ввод

| Поле | Ввод |
|---|---|
| Числа | `""` |

Ожидаемый результат:
```
Нет данных
```

Трассировка: `parts` пуст $\rightarrow$ выводится `Нет данных`, поиск максимума не запускается.

Фактический результат: совпадает с ожидаемым.

### unique.py

Алгоритм:
- Последовательный обход элементов исходного списка.
- Элемент добавляется в результирующий список только тогда, когда он ещё не встречался (`if num not in unique_numbers`).
- Множество `set` не используется, сохраняется порядок первого появления.

#### Таблица «ввод → ожидаемый ответ → фактический ответ»

| Ввод | Описание проверки | Ожидаемый ответ | Фактический ответ |
|---|---|---|---|
| `3 1 3 2 1` | Пример из методички с повторами | `[3, 1, 2]` | `[3, 1, 2]` (совпадает) |
| `1 2 3` | Список без повторов | `[1, 2, 3]` | `[1, 2, 3]` (совпадает) |
| `5 5 5` | Все элементы одинаковые | `[5]` | `[5]` (совпадает) |
| `""` | Пустой ввод | `[]` | `[]` (совпадает) |
| `-1 2 -1 0 2` | Повторы отрицательных и положительных чисел | `[-1, 2, 0]` | `[-1, 2, 0]` (совпадает) |

#### Проверка 1 — пример из методички

| Поле | Ввод |
|---|---|
| Числа | `3 1 3 2 1` |

Ожидаемый результат:
```
[3, 1, 2]
```

Пошаговая трассировка:
1. `num = 3`: `3 not in []` $\rightarrow$ добавляем: `unique = [3]`
2. `num = 1`: `1 not in [3]` $\rightarrow$ добавляем: `unique = [3, 1]`
3. `num = 3`: `3 in [3, 1]` $\rightarrow$ пропускаем
4. `num = 2`: `2 not in [3, 1]` $\rightarrow$ добавляем: `unique = [3, 1, 2]`
5. `num = 1`: `1 in [3, 1, 2]` $\rightarrow$ пропускаем
- Итог: `[3, 1, 2]`.

Фактический результат: совпадает с ожидаемым.

#### Проверка 2 — одинаковые числа

| Поле | Ввод |
|---|---|
| Числа | `5 5 5` |

Ожидаемый результат:

Трассировка:
1. Первое число `5` добавляется в список: `[5]`.
2. Второе и третье числа `5` уже присутствуют в списке и игнорируются.
- Итог: `[5]`.

Фактический результат: совпадает с ожидаемым.
