# Лабораторная работа 2. Вычисления и проверка результата

**Вариант:** 2 — Количество книг / Книг в коробке

## Как запустить

Все файлы находятся в папке `lab02`. Запуск из терминала, находясь в этой папке:

```bash
python time_parts.py
python purchase.py
python predict.py
python variant.py
python circle.py
```

Если команда `python` не найдена, используйте `python3`.

### predict.py

#### Фрагмент 1: `2 + 3 * 4`

- **Прогноз:** `14`
- **Результат Python:** `14`
- **Объяснение:** Умножение выполняется раньше сложения (приоритет операций). `3 * 4 = 12`, затем `2 + 12 = 14`.

#### Фрагмент 2: `(2 + 3) * 4`

- **Прогноз:** `20`
- **Результат Python:** `20`
- **Объяснение:** Круглые скобки переопределяют порядок действий. Сначала вычисляется сумма `2 + 3 = 5`, затем умножение `5 * 4 = 20`.

#### Фрагмент 3: `17 // 5`

- **Прогноз:** `3`
- **Результат Python:** `3`
- **Объяснение:** Оператор `//` выполняет целочисленное деление с округлением вниз (floor division). Число 5 укладывается в 17 три полных раза (`3 * 5 = 15`).

#### Фрагмент 4: `17 % 5`

- **Прогноз:** `2`
- **Результат Python:** `2`
- **Объяснение:** Оператор `%` возвращает остаток от целочисленного деления: `17 − 3 * 5 = 2`.

#### Фрагмент 5: `-7 // 2`

- **Прогноз:** `-4`
- **Результат Python:** `-4`
- **Объяснение:** В Python `//` всегда округляет частное вниз к ближайшему меньшему целому (к минус бесконечности). Точное частное `-7 / 2 = -3.5`. Наибольшее целое число, не превышающее `-3.5`, равно `-4` (а не `-3`, так как `-4 < -3.5`). Сохраняется равенство `-7 == (-4) * 2 + 1`.
