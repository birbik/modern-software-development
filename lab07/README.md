## Пояснения к работе функций

### Разница между возвратом (`return`) и выводом (`print()`)
- `print()` выводит переданные данные в стандартный поток вывода (на экран) для чтения человеком, но не возвращает значения в вызывающий код (возвращает `None`).
- `return` передаёт вычисленное значение обратно в точку вызова функции, позволяя сохранить результат в переменную, использовать его в дальнейших вычислениях или проверять инструкцией `assert`. Чистые вычислительные функции должны возвращать данные через `return`, не выполняя побочного вывода на экран.

### Разница между параметром и локальной переменной
- **Параметр** — переменная, объявленная в заголовке функции (`def f(x, y):`), через которую функция принимает входные аргументы извне при вызове.
- **Локальная переменная** — переменная, созданная внутри тела функции (например, счётчик `total = 0`). Она существует только во время выполнения вызова функции и недоступна за её пределами.

### Демонстрация теста, обнаруживающего ошибку
При реализации функции `select_numbers(numbers, threshold)` для Варианта 2 («Меньше порога») условие отбора должно быть строго меньше (`x < threshold`).

Если допустить ошибку и использовать нестрогое неравенство (`x <= threshold`):
```python
def select_numbers(numbers, threshold):
    return [x for x in numbers if x <= threshold]  # Ошибка: порог включен
```
При запуске `test_functions.py` проверка контрольного примера:
```python
assert select_numbers([-5, 0, 2, 5], 2) == [-5, 0]
```
немедленно вызовет исключение:
```
AssertionError
```
так как функция вернёт `[-5, 0, 2]`, ошибочно включив граничный элемент `2`. Автоматический тест гарантирует своевременное обнаружение ошибки.

## Проверки

### 1. sum_digits(number)

Правила:
- Принимает целое число любого знака.
- Вычисляет сумму цифр модуля числа через целочисленную арифметику (`% 10` и `// 10`).
- Для нуля возвращает `0`.

#### Таблица «ввод → ожидаемый ответ → фактический ответ»

| Ввод | Описание проверки | Ожидаемый ответ | Фактический ответ |
|---|---|---|---|
| `0` | Нулевое значение | `0` | `0` (совпадает) |
| `507` | Положительное трехзначное число с нулем внутри | `12` | `12` (совпадает) |
| `-507` | Отрицательное число | `12` | `12` (совпадает) |
| `9` | Однозначное число | `9` | `9` (совпадает) |
| `-100` | Отрицательное круглое число | `1` | `1` (совпадает) |

#### Проверка 1 — контрольный пример 507
- Модуль: $|507| = 507$
- Итерация 1: $507 \pmod{10} = 7$, $507 // 10 = 50$, сумма $= 7$
- Итерация 2: $50 \pmod{10} = 0$, $50 // 10 = 5$, сумма $= 7 + 0 = 7$
- Итерация 3: $5 \pmod{10} = 5$, $5 // 10 = 0$, сумма $= 7 + 5 = 12$
- Результат: `12`. Фактический результат совпадает.

#### Проверка 2 — отрицательное число -507
- Сначала вычисляется модуль: `abs(-507) = 507`.
- Пошаговое сложение цифр даёт $7 + 0 + 5 = 12$.
- Результат: `12`. Фактический результат совпадает.

### 2. average(numbers)

Правила:
- Принимает список чисел.
- Возвращает вещественное среднее значение.
- Для пустого списка возвращает `None` (без деления на 0).
- Исходный список не изменяется.

#### Таблица «ввод → ожидаемый ответ → фактический ответ»

| Ввод | Описание проверки | Ожидаемый ответ | Фактический ответ |
|---|---|---|---|
| `[]` | Пустой список | `None` | `None` (совпадает) |
| `[2, 4, 6]` | Список четных чисел | `4.0` | `4.0` (совпадает) |
| `[1, 2]` | Список с дробным средним | `1.5` | `1.5` (совпадает) |
| `[-5, 0, 2, 5]` | Числа разных знаков | `0.5` | `0.5` (совпадает) |

#### Проверка 1 — пустой список
- `not numbers` истинно $\rightarrow$ немедленный возврат `None`.

#### Проверка 2 — список [2, 4, 6]
- Сумма: $2 + 4 + 6 = 12$
- Количество: $3$
- Среднее: $12 / 3 = 4.0$. Фактический результат совпадает.

### 3. normalize_text(text)

Правила:
- Приведение текста к нижнему регистру.
- Удаление начальных и конечных пробелов.
- Замена любых последовательностей пробелов между словами на одиночный пробел.
- Пустая строка или строка только из пробелов даёт пустую строку `""`.

#### Таблица «ввод → ожидаемый ответ → фактический ответ»

| Ввод | Описание проверки | Ожидаемый ответ | Фактический ответ |
|---|---|---|---|
| `  ПРИВЕТ   Мир  ` | Контрольный пример с пробелами и разным регистром | `"привет мир"` | `"привет мир"` (совпадает) |
| `   ` | Строка только из пробелов | `""` | `""` (совпадает) |
| `Python` | Одно слово без пробелов | `"python"` | `"python"` (совпадает) |

#### Проверка 1 — контрольный пример
- `text.split()` извлекает слова `['ПРИВЕТ', 'Мир']`.
- `" ".join(...)` объединяет их через один пробел: `'ПРИВЕТ Мир'`.
- `.lower()` переводит в нижний регистр: `'привет мир'`.

### 4. select_numbers(numbers, threshold) — Вариант 2

Правила:
- Отбор элементов, строго меньших заданного порога (`x < threshold`).
- Порядок элементов и повторы сохраняются.
- Исходный список не изменяется.
- При отсутствии подходящих элементов возвращается пустой список `[]`.

#### Таблица «ввод → ожидаемый ответ → фактический ответ»

| Ввод | Порог | Описание проверки | Ожидаемый ответ | Фактический ответ |
|---|---|---|---|---|
| `[-5, 0, 2, 5]` | `2` | Контрольный пример из методички | `[-5, 0]` | `[-5, 0]` (совпадает) |
| `[]` | `2` | Пустой список | `[]` | `[]` (совпадает) |
| `[1, 2, 3]` | `2` | Граничные значения вокруг порога | `[1]` | `[1]` (совпадает) |
| `[-2, -1, 0, 1]` | `0` | Порог 0 | `[-2, -1]` | `[-2, -1]` (совпадает) |
| `[-5, 0, -5, 2]` | `2` | Повторяющиеся подходящие элементы | `[-5, 0, -5]` | `[-5, 0, -5]` (совпадает) |

#### Проверка 1 — контрольный пример
- Исходный список: `[-5, 0, 2, 5]`, порог `2`.
- Проверка условий:
  - $-5 < 2$ — истина, включаем `-5`
  - $0 < 2$ — истина, включаем `0`
  - $2 < 2$ — ложь (строго меньше), не включаем `2`
  - $5 < 2$ — ложь, не включаем `5`
- Итог: `[-5, 0]`.

### 5. is_palindrome(text)

Правила:
- Игнорирование регистра символов и пробелов.
- Знаки препинания не удаляются и сравниваются как есть.
- Пустая очищенная строка даёт `False`.

#### Таблица «ввод → ожидаемый ответ → фактический ответ»

| Ввод | Описание проверки | Ожидаемый ответ | Фактический ответ |
|---|---|---|---|
| `А роза упала на лапу Азора` | Классический палиндром с пробелами | `True` | `True` (совпадает) |
| `Шалаш` | Палиндром в разном регистре | `True` | `True` (совпадает) |
| `Python` | Обычное слово, не палиндром | `False` | `False` (совпадает) |
| `   ` | Строка из одних пробелов | `False` | `False` (совпадает) |
| `""` | Пустая строка | `False` | `False` (совпадает) |
| `А!` | Различие из-за знака препинания | `False` | `False` (совпадает) |
